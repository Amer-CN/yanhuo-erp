# ADR 0004：场次（Session）记账模型

- Status: Accepted
- Date: 2026-11-08

## Context

旧版按「自然日 + 实时收银」记账，无法表达「一次出摊从第一单到收摊」的口径，收摊后补记也会打乱日报。场次模型把一次出摊当作一个可结账、可补记的单元。

## Decision

新增 `sessions` 表；每台设备第一笔记账时自动开一场（`status: open`），收摊结账写 `summary` 快照并置 `closed`；已结账场次只允许「补记」（`patchedCount + 1`，重算快照）与整单作废；报表默认看本场或历史场次。

## Consequences

- 正面：报表口径稳定；收摊后有明确汇总；补记不重写历史场次。
- 代价：订单必须挂 `sessionId`，旧数据通过 `migrateSessions` 按「自然日 + 4 小时间隔」回填；迁移不可逆，因此 T07 在迁移前自动落 `pre-migrate` 快照。
- 边界：场次按设备归属（报表只看本机场次）；跨设备数据通过「销售记录」查看。
