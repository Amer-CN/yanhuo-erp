## 四、待补项（1 条，非重构）

**`costIncomplete` 真修复**（`calc.ts` `productMarginsBySession`）

- **现状**：P1-A 补了 `if (lineCost === undefined) cur.costIncomplete = true`，但这只在
  `fifo` 与 `orders` 不同步（陈旧 `FifoResult`）时触发。生产调用链
  （`App.tsx:54` → `ReportPage:113`）中两者同源，**该判定实际不可达**。
- **为什么"漏录进货"不触发**：`fifoAllocate` 对每条参与重放的明细都会 `lineCost.set()`，
  无批次时用兜底均价（完全无批次则为 0），所以 key 存在、值为 0，不是 `undefined`。
- **真修复方案**：`fifoAllocate` 增加 `lineUncovered: Map<string, number>`（每条明细未覆盖数量），
  `productMarginsBySession` 据此判定。需同步修改 `tests/calc.test.ts` 中手工构造
  `FifoResult` 的位置。
- **时机**：与"商品行显示成本估算标记"的功能一起做，单独补字段无 UI 消费、无用户价值。
