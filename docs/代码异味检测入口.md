## 七、这一轮重构的关键经验

1. **先删后拆**：P0 删掉 5 个死代码导出，后续拆分才有干净基底。
2. **按风险分批，而不是按数量分批**：UI 拆分与同步层拆分必须分开做，前者能靠 a11y/e2e 兜住，后者只能靠人工真机。
3. **每批独立 commit**：13 个 commit 中任何一个都能单独回滚。
4. **测试与代码同步删**：P0 删 `dayReport` 时漏了 `tests/calc.test.ts` 的 3 个用例，差点卡住构建；基线第十一节已把这条写成维护约定。
5. **报告偏差比掩盖偏差有价值**：`costIncomplete` 不可达、重渲染无法测量、假 Supabase 未验真实云端——这三处坦白让每轮核对都有真实锚点。
