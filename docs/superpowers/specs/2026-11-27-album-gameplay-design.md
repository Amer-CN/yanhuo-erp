# 卡册玩法设计（图鉴 + 战报，2026-11-27）

> 依据：[收藏玩法方案](2026-11-27-collection-gameplay-options.md) 已选 **A 图鉴收集** + 三项附加（品质样张、赛季战报、卡面差异）。
> 本文只定玩法与验收，不定具体实现细节；确认后再写实施计划。

## 目标

打开卡册就有「我们今年的收成」；卡片之间有差异、有等级；赛季结束有一页能截图讲给别人听的战报。

## 非目标

自由 360° 旋转、惯性甩动、随机抽卡 / 开包、商品照片、交易、个人贡献拆分。

## Phase 1：开赛前就能看、能玩

### 1. 交互收口（替代自由旋转）

- 详情卡：**受控倾斜**（最大 ±12°）+ 光泽随倾斜移动 + **点按翻面 180°**（弹簧收住）。
- 倾斜输入**二选一**：设备有体感权限就用体感，否则用触摸；同一张卡上不同时生效。`n- 倾斜实现当前改用 `react-parallax-tilt`（MIT）做对比：它负责触摸/陀螺仪/glare，我们只保留翻面与权限申请。
- 体感基准**只在打开卡片时取一次**，触摸不再重置基准——消除「一碰就回正」。
- 网格卡保持静态，不做悬浮旋转。

### 2. 卡面差异（不靠照片）

同一套模板，靠三层信息区分：

| 层 | 内容 | 规则 |
|---|---|---|
| 分类纹样 | 炮 / 烟花 / 儿童 / 组合 各一种低对比底纹 | 不抢商品名；不引入新饱和色 |
| 品质边框 | R / SR / SSR / UR | 现有品质色；UR 保留彩虹边 |
| 徽章 | 本季毛利 Top3 名次、「本季最赚」、已停售、新商品 | 最多显示 2 枚，避免拥挤 |

另外每张卡给**稳定卡号**（分类内按排序与名称，`#01` 起），让它像一本图鉴。

### 3. 品质样张预览

- 卡册页入口「看品质样张」→ 打开一张 Sheet，横排 4 张样卡：R / SR / SSR / UR，各标门槛金额。
- 样卡用演示名（如「示例 · 大礼花」）并明确标注「样张，不计入收集」。
- 目的：不用等 12-25 才见到金卡、闪卡长什么样。

### 4. 完成度

- 头卡增加一行：`已收集 X / Y 种 · SR 以上 Z 种`。
- 分类筛选 chip 保持现状，不额外加进度条（避免页面变重）。

## Phase 2：赛季结束的惊喜

### 5. 赛季战报

入口：往季归档行点开「赛季战报」Sheet；当前赛季可预览并标「进行中」。

内容（全部从现有账本实时计算，与报表同一口径）：

- 赛季名与起止日期；
- 毛利、订单数、售出件数、平均每单毛利；
- 品质分布：R / SR / SSR / UR 各几张；
- 毛利 Top 5 商品（名称、毛利、品质）；
- 与上一季毛利对比（正负百分比）；
- 「复制文字战报」按钮（方便发微信，不用截图也能讲）。

成本待补的明细不计入，并在战报底部注明「N 条明细因成本待补未计入」。

## 口径与边界

- 一切数字沿用 `src/db/album.ts` 的 `buildSeasonLedger`，不新增数据表、不改同步协议。
- 卡号、徽章、样张都是**纯展示**，不写入账本。
- 战报只读本机账本；离线可看。
- 不做分享图片生成（先靠系统截图），避免引入 canvas 依赖。

## 验收

- 任何时候打开卡册：有卡片、有完成度、有样张入口。
- 详情卡不会自转；点按能翻面；触摸与体感不会同时改倾斜；触摸后倾斜不再突然回正。
- 样张四档样式正确，且不进入真实收集统计。
- 战报数字与报表一致；往季、当季预览、无数据赛季三种情况都有明确显示。

## 实施顺序

1. 交互收口（去掉自由旋转与惯性，受控倾斜 + 翻面 + 体感基准只取一次）。
2. 卡面差异（分类纹样、卡号、徽章）。
3. 品质样张 + 完成度。
4. 赛季战报（Phase 2）。

前 3 步做完，卡册在开赛前就已经好看、能看懂目标；第 4 步在 12 月底前完成即可。
