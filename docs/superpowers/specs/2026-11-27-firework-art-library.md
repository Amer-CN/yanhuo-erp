# 烟花爆竹卡面素材库（设计草案，2026-11-27）

> 目标：不靠商品照片，用一套原创插画让每张卡都有辨识度；默认按名字自动匹配，尽量不需要手动选。

## 先给结论

**不要「一个商品名 = 一张独立画」**，那是无底洞。你举的例子本身就能拆成两层：

- `加特林` → 家族 **加特林**
- `黄金加特林` → 家族 **加特林** + 变体 **黄金**
- `网红风车蜻蜓` → 家族 **风车/蜻蜓**（复合意象）+ 修饰词 **网红**

所以素材库 = **家族母题（约 20 个）+ 变体效果（约 6 种）**，组合出上百种卡面，默认按名字匹配，匹配不到才退回分类图。

## 匹配规则（纯函数，可测）

1. 归一化：去空格、标点、年份、发数、口径等数字。
2. 去营销词：网红、新款、爆款、正品、特价、加大、大号、迷你。
3. 家族匹配：按别名长度从长到短命中，优先长词（`风车蜻蜓` 优先于 `风车`）。
4. 复合意象：允许命中两个家族，第一个做主画面，第二个做角标/底纹。
5. 变体匹配：黄金/白银/蓝焰/七彩/夜光/迷你。
6. 兜底：都没命中 → 用分类图（现有四类插画），不报错。
7. 结果带 `confidence`：低置信度时界面给「可能不是这张」并提供一键换图。

## 自动 vs 手动

- **默认全自动**：进货/新建商品时名字一存，卡片立即有图。
- **保留一键替换**：商品管理里加「卡片样式」，只在自动匹配不满意时用；不用你每次选。
- 理由：自动是主路径，替换是保险；没有替换的话，遇到怪名字只能忍着。

## 出图方式

- 全部原创 SVG，沿用「夜间余烬」深色底 + 玻璃质感，不引入第三方美术。
- 每个家族一张母题，变体用 CSS/SVG 渐变与粒子覆盖，不重复画。
- 第一版先画 **10 个高频家族**（加特林、水母、风车、蜻蜓、孔雀、喷泉、仙女棒、二踢脚、鞭炮、向日葵），验证风格后再补。

## 风险

- **名字是你们自己起的**：别名表要以你实际货名为准，否则自动匹配会漏。建议你把实际商品名发我（或允许我本机只读导出商品列表，不写账本）。
- 复合名（网红风车蜻蜓）容易歧义：用「最长别名 + 主次两级」处理。
- 画风未验证就批量画，返工成本高：先出 3 张样张给你看。
