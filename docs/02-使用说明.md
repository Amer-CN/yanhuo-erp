> 应用地址（手机装到桌面就是这个）：**<https://amer-cn.github.io/yanhuo-erp/>**
>
> 写给摊位现场用的人看，步骤越少越好。
>
> **本轮状态：本地修复候选已验证，外部验收待完成。** 下文涉及恢复、重连、事务清云和更新入口的是候选操作说明；候选未部署，线上旧版未必已有相同入口。由维护者确认当前构建后再操作；两台目标手机尚未完成本轮验收。

## 一、第一次装（只做一次）

1. **一台手机先打开上面的地址**，按提示「添加到主屏幕」。
   - 安卓 Chrome：右上角 ⋮ → 添加到主屏幕
   - iPhone Safari：分享 → 添加到主屏幕（必须用 Safari，微信里打开的不行）
2. 进「更多 → 商品管理」，把示例商品改成自己的货：
   - 改名、改价、改「1 箱 = 几个」
   - 用不上的点「停用」，别删（有流水的删不掉）
3. **另一台设备装好后，确认两台使用同一本账**：
   - 云同步正常时，等两台“上次同步”更新、待推送归 0，再核对商品。
   - 没开云同步时：第一台“导出备份”发给第二台，第二台“导入并合并”，先看预览再确认。
   - 同一种新商品只在一台建；两边分别新建会得到不同记录，可能重复。

## 二、第一次打开

- 8 个商品是**示例**，有「示例」角标，库存为 0 也能卖；去「更多 → 商品管理」改成自己的货（改过任意字段就不再是示例）。
- 在“更多 → 设置与同步 → 本机与操作人”分别填写两台设备名和本机操作人编号（如 001 / 002）；本机身份不随云同步覆盖。

### 云同步（默认已开启，不用设置）

打开应用就会自动用内置账本同步，**两个人不用填任何东西**：

- 两台手机打开同一个网址，就是同一本账
- 一台开单，另一台联网后自动看到；断网照常卖，联网自动补发
- 「更多 → 设置与同步 → 云同步」能看到状态、上次同步、待推送条数；“已连接”还需配合上次同步时间和两台数据核对
- 恢复备份、撤销合并或清空后会显示“已暂停，待确认”，重启也不会自动恢复同步；按第五节先预览再接入
- 想换成自己的同步码，再按[云同步设置](03-云同步设置.md)操作；远端未完成协议升级时不能直接换账本
- 手动导出/导入保留，只当备份

## 三、摊位上怎么用

### 开单（最常用）

1. 开始本机场次后点“记一笔”→“添加商品”→ 选商品 →“完成（回单据）”。
2. 核对每行数量、按个/按箱、成交金额和付款方式；保存前可继续修改。
3. 新单点“只保存”返回，或“保存并记下一单”继续记新单；保存后看回执，按错可在提供的撤销入口处理。
4. 销售记录里编辑已有单时只有“保存修改”，保存后回列表；补记会明确显示目标场次，“保存并继续补记”仍写入同一目标场次。
5. 在编辑或补记中建商品，返回后先核对原单/目标场次和草稿，再保存。提交中等待结果，避免重复点击。

页面若显示加载失败，可点“重试本页”；失败仍在时先保留草稿，再联系维护者。

### 断网
**断网也能开单**，数据存在手机本地。两台手机各自记，互不影响。
店没客人时切去“库存”再回来，仍应能看到未保存的单据草稿；保存前再次核对商品和金额。

### 进货
1. 底部「进货」→ 选商品
2. 填数量、进价（批次信息可选，展开填批号/生产日期/有效期/厂家）
3. 「保存这一条」在必填项下面，不会藏到折叠线下
4. 点「今天已录 N 条」可以查看/删错

## 四、收摊

1. **对账**：底部「报表」→「当日」
   - 销售额、现金、微信、支付宝 → 和钱箱对
   - 毛利 → 今天赚了多少
   - 砍价让利 → 今天让出去多少
2. **两台设备对账**：
   - **开了云同步**：不用手动合并，联网会自动同步；点「设置与同步」能看到上次同步时间和待推送条数。
   - **没开云同步**：手动合并——任意一台「设置与同步 → 导出备份」发微信 → 另一台「导入并合并」→ 先看预览 → 勾选「先导出本机备份」→「合并这些数据」。
   - 合并只增不减，同一条记录不会重复；设置里的操作人按设备保留。
   - 合错了可在结果页点“撤销合并”，**仅本机**回到合并前；云端未回滚，另一台独有记录保留，同步保持暂停。按第五节核对差异后重新接入。
3. **备份**：导出一次，发到微信文件传输助手/收藏。苹果手机尤其要每天备份（Safari 长时间不打开可能清缓存）。

## 五、常见问题

| 情况 | 怎么办 |
|---|---|
| 库存显示负数 | 卖超了或漏录进货。去「进货」补录，或「库存 → 点商品 → 修正库存」记盘亏 |
| 两台设备库存对不上 | 先看待推送和上次同步时间，再核对同一场次；持续不一致时各导出备份，按运维手册排查，不要反复清数据 |
| 毛利偏高 | 有销量没对应进货批次，报表顶部会有红字提示，去补录进货 |
| 改错了单 | 更多 → 销售记录 → 点开那张单 → 整单作废（库存会自动加回来） |
| 换手机 | 新手机装好，导入旧手机导出的备份即可 |
| 想清空重来 | 两台先导出备份；区分只清本机和清整个云账本，见下文。提交后等待结果，不用取消代替中止 |
| 有新版本但点过“稍后” | 更多 → 设置与同步 → 应用更新；收摊后检查更新，再“更新并重新打开”，可向维护者提供当前构建标识 |

### 恢复 / 撤销合并后重新接入

1. 先核对恢复后的单数、明细和金额；云同步保持“已暂停，待确认”，云端和另一台的数据未被回滚。
2. “云同步 → 准备重连”只读取差异。仅本机的记录保留并待上传，仅云端的记录带回本机；同一订单连同明细作为一组，对每组内容不同的记录明确选择“采用本机版本”或“采用云端版本”。
3. 选择本机订单会以该单完整明细为准，包括删除云端该单多出的旧明细；先核对再确认。预览期间另一台有新改动时应重新预览，不能强行套用旧结果。
4. 缺少条件上传能力或预览过期时按提示停下并联系维护者；“暂不接入”会继续保持暂停。确认接入后再核对上次同步、待推送和另一台的结果。

### 清空时看清范围

- 只清本机：不清云端；完成后同步暂停，重新接入仍需预览。
- 同时清云端：会清整个账本，其他设备也需重新核对；维护者须先完成远端协议升级。没有所需 RPC 时拒绝操作并保留本机数据。
- 显示“结果未知”时，本机数据仍保留；用“重试同一次清空”确认原操作，**不要另起一次清空**。操作编号供维护者核对，具体见[运维手册](08-运维手册.md#4-误清数据)。

## 六、成本怎么算的

- 每批进货单独记成本，卖货时按**先进先出**扣批次 → 毛利 = 销售额 − 这批货的进价
- 所以进货时「进价」一定要填对，否则毛利不准
- 允许事后补录进货，补录后报表自动重算
