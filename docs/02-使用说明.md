# 使用说明（摆摊版）

> 应用地址（手机装到桌面就是这个）：**<https://amer-cn.github.io/yanhuo-erp/>**
>
> 写给摊位现场用的人看，步骤越少越好。
>
> **本轮状态：本地候选与独立真实协议验收通过，生产/两台目标手机尚待人工验收。** 下文涉及恢复、重连、事务清云和更新入口的是候选操作说明；候选未部署，线上旧版未必已有相同入口。由维护者确认当前构建后再操作；本机通过不等于手机或营业日通过。

## 一、第一次装（只做一次）

1. **一台手机先打开上面的地址**，按提示「添加到主屏幕」。
   - 安卓 Chrome：右上角 ⋮ → 添加到主屏幕
   - iPhone Safari：分享 → 添加到主屏幕（必须用 Safari，微信里打开的不行）
2. 进「更多 → 商品管理」，把示例商品改成自己的货：
   - 改名、改价、改「1 箱 = 几个」
   - 用不上的点「停用」，别删（有流水的删不掉）
3. **另一台设备装好后，确认两台使用同一本账**：
   - 云同步正常时，等两台“上次同步”更新、待推送归 0，再核对商品。
   - 没开云同步时：第一台“导出备份”发给第二台，第二台“导入并合并”，先看预览再确认。
   - 同一种新商品只在一台建；两边分别新建会得到不同记录，可能重复。

## 二、第一次打开

- 8 个商品是**示例**，有「示例」角标，库存为 0 也能卖；去「更多 → 商品管理」改成自己的货（改过任意字段就不再是示例）。
- 在“更多 → 设置与同步 → 本机与操作人”分别填写两台设备名和本机操作人编号（如 001 / 002）；本机身份不随云同步覆盖。

### 云同步（默认已开启，不用设置）

打开应用就会自动用内置账本同步，**两个人不用填任何东西**：

- 两台手机打开同一个网址，就是同一本账
- 一台开单，另一台联网后自动看到；断网照常卖，联网自动补发
- 「更多 → 设置与同步 → 云同步」能看到状态、上次同步、待推送条数；“已连接”还需配合上次同步时间和两台数据核对
- 恢复备份、撤销合并或清空后会显示“已暂停，待确认”，重启也不会自动恢复同步；按下方“恢复 / 撤销合并后重新接入”先预览再接入
- 想换成自己的同步码，再按[云同步设置](03-云同步设置.md)操作；远端未完成协议升级时不能直接换账本
- 手动导出/导入保留，只当备份

## 三、摊位上怎么用

### 开单（最常用）

1. 开始本机场次后点“记一笔”→“添加商品”→ 选商品 →“完成（回单据）”。
2. 核对每行数量、按个/按箱、成交金额和付款方式；保存前可继续修改。
3. 新单点“只保存”返回，或“保存并记下一单”继续记新单；保存后看回执，按错可在提供的撤销入口处理。
4. 销售记录里编辑已有单时只有“保存修改”，保存后回列表；补记会明确显示目标场次，“保存并继续补记”仍写入同一目标场次。
5. 在编辑或补记中建商品，返回后先核对原单/目标场次和草稿，再保存。提交中等待结果，避免重复点击。

页面若显示加载失败，按页面提示“重新打开应用”；未保存的单据草稿会保留。若问题仍在，先保留草稿并联系维护者。

### 断网
**断网也能开单**，数据存在手机本地，联网后自动补发；底栏会显示「离线 · 待上传」。两台手机离线时各自记账，联网后再核对待推送、上次同步和单据集合。

### 进货
1. 底部「进货」→「选商品」→ 点商品。
2. 填数量、进价；批次信息（批号 / 生产日期 / 有效期 / 厂家）可选，展开后再填。
3. 点「保存这一条」后数量会清空，商品和批次信息保留，方便照送货单连续录。
4. 展开「今天已录 N 条」可查看并删错。

### 库存
- 底部「库存」查看商品余量与成本；负数表示欠货（卖超了）。
- 盘点少了 / 多了：点商品 →「修正库存（盘亏 / 盘盈）」→ 选「少了」或「多了」→ 填数量。

## 四、收摊

1. **结账**：底部「记账」→ 本场卡右上「收摊结账」→ 看预览（待同步条数、缺成本、负库存都会提示）→ 确认。
   - 结完发现漏单：点「撤销结账」回到进行中，或在该场点「补记」补到已结账场次。
2. **对账**：底部「报表」→ 顶部「今天 · 已结账 N 场 · ¥X」汇总。
   - 现金 / 微信 / 支付宝与钱箱核对；毛利、让利和作废单在下方，作废单可逐单撤销。
   - 「复制本场汇总」可发到微信。
3. **两台设备对账**：
   - **开了云同步**：联网会自动同步；「更多」页可看上次同步时间与待推送条数。
   - **没开云同步**：一台「设置与同步 → 导出备份」发微信，另一台「导入并合并」；先看预览、勾选「先导出本机备份」再确认合并。
   - 合并后若要撤销，只恢复本机；云端未回滚、另一台数据保留且同步暂停。按本节下方“恢复 / 撤销合并后重新接入”重新预览，不要将撤销理解为两端回滚。
4. **备份**：结账后应用会在本机保存快照（最近 3 个日期）；另手动「导出备份」发微信更稳。苹果手机尤其建议每天导出，避免 Safari 清理本机存储。

## 五、常见问题

| 情况 | 怎么办 |
|---|---|
| 库存显示负数 | 卖超了或漏录进货。去「进货」补录，或「库存 → 点商品 → 修正库存」记盘亏 |
| 两台设备库存对不上 | 先看待推送和上次同步时间，再核对同一场次；持续不一致时各导出备份，按运维手册排查，不要反复清数据 |
| 毛利偏高 | 有销量没对应进货批次，报表顶部会有红字提示，去补录进货 |
| 改错了单 | 更多 → 销售记录 → 点开那张单 → 整单作废（库存会自动加回来） |
| 换手机 | 新手机装好，导入旧手机导出的备份即可 |
| 想清空重来 | 两台先导出备份；区分只清本机和清整个云账本，见下文。提交后等待结果，不用取消代替中止 |
| 有新版本但点过“稍后” | 更多 → 设置与同步 → 应用更新；收摊后检查更新，再“更新并重新打开”，可向维护者提供当前构建标识 |

### 恢复 / 撤销合并后重新接入

1. 先核对恢复后的单数、明细和金额；云同步保持“已暂停，待确认”，云端和另一台的数据未被回滚。
2. “云同步 → 准备重连”只读取差异。仅本机的记录保留并待上传，仅云端的记录带回本机；同一订单连同明细作为一组，对每组内容不同的记录明确选择“采用本机版本”或“采用云端版本”。
3. 选择本机订单会以该单完整明细为准，包括删除云端该单多出的旧明细；先核对再确认。预览期间另一台有新改动时应重新预览，不能强行套用旧结果。
4. 缺少条件上传能力或预览过期时按提示停下并联系维护者；“暂不接入”会继续保持暂停。确认接入后再核对上次同步、待推送和另一台的结果。

### 清空时看清范围

- 只清本机：不清云端；完成后同步暂停，重新接入仍需预览。
- 同时清云端：会清整个账本，其他设备也需重新核对；维护者须先完成远端协议升级。没有所需 RPC 时拒绝操作并保留本机数据。
- 显示“结果未知”时，本机数据仍保留；用“重试同一次清空”确认原操作，**不要另起一次清空**。操作编号供维护者核对，具体见[运维手册](08-运维手册.md#4-误清数据)。

## 六、成本怎么算的

- 每批进货单独记成本，卖货时按**先进先出**扣批次 → 毛利 = 销售额 − 这批货的进价
- 所以进货时「进价」一定要填对，否则毛利不准
- 允许事后补录进货，补录后报表自动重算
## 七、我们的卡册

「更多 → 我们的卡册」把卖出去的毛利收集成商品卡，一个春节赛季玩一遍。

### 赛季

- 每年 **12 月 25 日（圣诞节）** 开赛，到次年**元宵节**结束；赛季结束自动归档，下个赛季从 0 重新收集。
- 元宵节后到当年 12 月 25 日前的销售不计入卡册；但这段时间打开卡册**照样能看能玩**，页面显示最近收官的那一季（头卡标「已收官」）。
- 补记到旧场次的单仍算回那场所在的赛季，不会算进补记当天。

### 两种进度

| 进度 | 看什么 | 档位 |
|---|---|---|
| 卡册等级 | 本赛季**夫妻合计**毛利 | Lv.1 ¥0、Lv.2 ¥2,500、Lv.3 ¥5,000、Lv.4 ¥7,500、Lv.5 ¥10,000；之后每多 ¥10,000 升一级 |
| 商品卡品质 | 本赛季**这一件商品**的毛利 | R ¥0、SR ¥50、SSR ¥200、UR ¥500 |

- 品质越高，卡面边框与流光越足；UR 是彩虹闪卡。
- 卡册跟随**当前有效毛利**：作废订单、退货、修正成本后，卡片会相应升降级，不保留已经降级的旧状态。
- 销售额为 0 的赠品会按成本冲减毛利，所以送得太多也会拖慢进度。

### 成本待补

只有成本完整的销售才计入卡册。若有销量没对应进货批次，卡册页会提示「有 N 笔销售的成本待补，暂不计入」——去「进货」补录后自动恢复。

### 卡片交互

- 点格子里的卡 → 打开大卡详情。
- 手指横向拖动可 360° 旋转：扫一屏能转大半圈到一圈；松手后按速度继续转、慢慢停下；轻点回正或翻面。
- 体感倾斜不需要找开关：第一下摸卡片时会自动申请权限（iOS 必须由触摸触发，且需 HTTPS），之后轻微跟随手的倾斜；手指拖动或卡片还在惯性旋转时，体感会自动让位，不会和旋转打架。
- 系统开了「减弱动态效果」时，惯性、流光和自动动画都会关掉。

### 卡册页里的其他信息

- 顶部显示赛季名、起止日期、本赛季毛利、当前等级和下一级差额。
- 可按分类（炮 / 烟花 / 儿童 / 组合）和品质筛选；停售商品排在最后并标「已停售」。
- 底部「往季归档」列出以前赛季的最终等级和毛利，点击不进详情，只做回顾。
