# 使用说明（摆摊版）

> 应用地址（手机装到桌面就是这个）：**<https://amer-cn.github.io/yanhuo-erp/>**
>
> 写给摊位现场用的人看，步骤越少越好。

## 一、第一次装（只做一次）

1. **一台手机先打开上面的地址**，按提示「添加到主屏幕」。
   - 安卓 Chrome：右上角 ⋮ → 添加到主屏幕
   - iPhone Safari：分享 → 添加到主屏幕（必须用 Safari，微信里打开的不行）
2. 进「更多 → 商品管理」，把示例商品改成自己的货：
   - 改名、改价、改「1 箱 = 几个」
   - 用不上的点「停用」，别删（有流水的删不掉）
3. **另一台设备装好后，从第一台同步商品**：
   - 第一台：更多 → 设置与同步 → 导出备份（发微信）
   - 第二台：更多 → 设置与同步 → 导入并合并
   - ⚠️ 以后新商品只在第一台建，建完再合并给第二台，否则两边各建一套会重复。

## 二、第一次打开

- 8 个商品是**示例**，有「示例」角标，库存为 0 也能卖；去「更多 → 商品管理」改成自己的货（改过任意字段就不再是示例）。
- 开单页右上角的小胶囊是操作人，点一下可切换「我 / 老婆」，开关单会自动带上当前选择。

### 云同步（默认已开启，不用设置）

打开应用就会自动用内置账本同步，**两个人不用填任何东西**：

- 两台手机打开同一个网址，就是同一本账
- 一台开单，另一台联网后自动看到；断网照常卖，联网自动补发
- 「更多 → 设置与同步 → 云同步」能看到状态、上次同步、待推送条数
- 想换成自己的同步码，再按 [`03-云同步设置.md`](03-云同步设置.md) 操作
- 手动导出/导入保留，只当备份

## 三、摊位上怎么用

### 开单（最常用）
1. 底部「开单」→ 点分类（炮/烟花/儿童/组合）→ 点商品
2. 同一个商品点多下就是多件
3. 点底部「🧺 N 件」打开购物车：
   - 数量 +/−
   - 按「个」还是按「箱」卖，可以切换（切回会自动还原原来的数量）
   - 砍价：点「改价」，填成交价（会显示新合计和让利）
4. 结算 → 选现金/微信/支付宝
   - 选**现金**会问顾客给了多少，自动算找零（有 50/100/200 快捷键）
   - 收款完成后有「完成 / 撤销」，按错了可以直接撤销这一单

### 断网
**断网也能开单**，数据存在手机本地。两台手机各自记，互不影响。
店没客人时切去「库存」看一眼再回来，购物车也不会丢。

### 进货
1. 底部「进货」→ 选商品
2. 填数量、进价（批次信息可选，展开填批号/生产日期/有效期/厂家）
3. 「保存这一条」在必填项下面，不会藏到折叠线下
4. 点「今天已录 N 条」可以查看/删错

## 四、收摊

1. **对账**：底部「报表」→「当日」
   - 销售额、现金、微信、支付宝 → 和钱箱对
   - 毛利 → 今天赚了多少
   - 砍价让利 → 今天让出去多少
2. **两台设备对账**：
   - **开了云同步**：不用手动合并，联网会自动同步；点「设置与同步」能看到上次同步时间和待推送条数。
   - **没开云同步**：手动合并——任意一台「设置与同步 → 导出备份」发微信 → 另一台「导入并合并」→ 先看预览 → 勾选「先导出本机备份」→「合并这些数据」。
   - 合并只增不减，同一条记录不会重复；设置里的操作人按设备保留。
   - 合错了可以在结果页点「撤销合并」，账本回到合并前。
3. **备份**：导出一次，发到微信文件传输助手/收藏。苹果手机尤其要每天备份（Safari 长时间不打开可能清缓存）。

## 五、常见问题

| 情况 | 怎么办 |
|---|---|
| 库存显示负数 | 卖超了或漏录进货。去「进货」补录，或「库存 → 点商品 → 修正库存」记盘亏 |
| 两台设备库存对不上 | 正常，各自是本地估算。合并后「报表」里才是准的 |
| 毛利偏高 | 有销量没对应进货批次，报表顶部会有红字提示，去补录进货 |
| 改错了单 | 更多 → 销售记录 → 点开那张单 → 整单作废（库存会自动加回来） |
| 换手机 | 新手机装好，导入旧手机导出的备份即可 |
| 想清空重来 | 更多 → 设置与同步 → 清空全部数据（先导出备份） |

## 六、成本怎么算的

- 每批进货单独记成本，卖货时按**先进先出**扣批次 → 毛利 = 销售额 − 这批货的进价
- 所以进货时「进价」一定要填对，否则毛利不准
- 允许事后补录进货，补录后报表自动重算
