### 4. 复核发现的新问题：T09 缺列时仍不同步远端编辑

- **证据**：`src/db/syncResolve.ts` 中 `const remoteTime = Number(remoteRecordUpdatedAt) || 0;`；`sync.ts` 的降级分支只删除 `record_updated_at` 字段并继续推送旧格式。
- **推导**：未执行迁移时远端列恒为 0，本地 `businessTime(cur)` 通常 > 0 → `remoteTime < localTime` → 返回 `keep-local`。**远端编辑在 SQL 执行前仍不会生效**。
- **与手测的关系**：执行报告中的 ¥25→¥30 手测通过，说明所用的 mock/环境返回了 `record_updated_at`；真实云端在迁移前行为不同。
- **修复**：`Number(remoteRecordUpdatedAt) || businessTime(remote)`，并补两条表驱动用例。已写入 `docs/06` **T09b**（0.2–0.5 人日，建议 push 前完成）。
- **影响面**：只改纯函数与测试，无 schema、无 UI、无数据迁移，风险低。
